# CAD for led strip project !

## Components 3D

Some KiCAD parts were missing a 3D view, in `components` there is:
- pots: AI generated basic shape.
- L1: hand crafted.

## CAD requirements

- A plastic case must enclose PCB and battery.
- USB and LED socket shall be accessible from outside the case.
- The case must be easily disassembled using screw.
- Case must be printable on most 3D printers.
